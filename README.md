# Фрагмент адаптивного лендинга с применением CSS Grid

Учебный проект, созданный для практической отработки навыков построения современных и гибких сеток с помощью технологии **CSS Grid Layout**.

![Скриншот веб страницы](images/veb-screen.png)

🔗 **Посмотреть результат:** [Ссылка на ваш GitHub Pages](razzhivinasasha.github.io/grid-card/)

### 🎯 Цели и задачи работы:
- Изучить работу с сетками (Grid) на реальном фрагменте страницы.
- Реализовать адаптивность для мобильных телефонов и планшетов.
- Закрепить свойства `grid-template-columns`, `grid-gap` и работу с адаптивными медиа-запросами (`@media`).

## 🛠️ Стек технологий и инструменты:
- **HTML5** — семантическая структура проекта.
- **CSS3 (Flexbox/Grid)** — стилизация кнопок, дисплея и адаптивная сетка.
- **Адаптивный дизайн (Media Queries)** — ручная настройка сетки для планшетов и мобильных устройств, чтобы сайт выглядел аккуратно на любом экране.

## 🎨 Особенности проектирования макета:
- **Разработка без готового макета:** В отличие от стандартной верстки готовой страницы с Figma, данный интерфейс был полностью спроектирован мной самостоятельно.
- **Работа с референсами:** За визуальную основу и концепт были взяты дизайн-решения с официального сайта автомобилей Bugatti. Я проанализировала структуру премиального бренда и перенесла её эстетику в собственный код.
- **Самостоятельный UI/UX-дизайн:** Я сама продумала расположение блоков, композицию элементов, сетку карточек и логику адаптивного поведения интерфейса при изменении экранов.
